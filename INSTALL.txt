ALCHEMIST REACTION TIMER

INSTALL THE ARCHIVE MATCHING YOUR DUNGEON HELPER VERSION.
NEVER install ReactionTimer-X.Y.Z-source.zip into Dungeon Helper.

=== DUNGEON HELPER 4 (4.2.1.0, Windows .NET 8) ===
Install ReactionTimer-X.Y.Z-dh4-plugin.zip directly.
1. Close DDO. Open Dungeon Helper Settings > Add plugin from zip file.
2. Select ReactionTimer-X.Y.Z-dh4-plugin.zip.
3. If asked to overwrite the existing ReactionTimer folder, choose Yes.
4. Fully exit Dungeon Helper from its tray icon, restart it, then launch DDO.

If DH 4 refuses the update or reports a file in use:
Close DDO and DH, extract the ZIP, and copy the contents of plugins\ReactionTimer
into %APPDATA%\Dungeon Helper\plugins\ReactionTimer\ while keeping settings/logs.

=== DUNGEON HELPER 5 BETA (5.3.0.0, x64, DirectX 10/11) ===
Install ReactionTimer-X.Y.Z-dh5-plugin.zip directly (signed community entitlement).
1. Close DDO. Open Dungeon Helper 5 Beta Plugins > Install from zip.
2. Select ReactionTimer-X.Y.Z-dh5-plugin.zip.
3. Launch DDO in DX10 or DX11 (x64). Settings live under:
   %LocalAppData%\DungeonHelperData\plugins\Alch Reaction Timer\

USE
- DH 4: Click the amber stopwatch icon. Settings / effects sets Font size (px)
  10-160 (default 28), Theme (EberronGold / CannithArcane / FeywildTwilight),
  SuppressAlertsInTown, ShowDepletionBar, and RespikeAlertSeconds (0-60, default 5).
  Click Preview, then Move (20s) to drag the transparent click-through HUD.
- DH 5 Beta: Toggle the Material-tabbed window from the DH 5 plugin bar, or use
  /alch status | /alch warn <0-10> | /alch hud [on|off|pill|donut] |
  /alch town [on|off] | /alch theme <eberron|cannith|feywild> |
  /alch respike | /alch reset.

LOSSLESS SCALING (DH 4)
Status should show Capture exclusion: ON (Windows accepted WDA_EXCLUDEFROMCAPTURE;
Wine/Proton shows a fallback note). Test Preview with the settings panel closed
in both WGC and DXGI. DH 5 renders directly inside DDO's DX10/11 frame.
